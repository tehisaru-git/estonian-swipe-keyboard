# Viipio keyboard v0.3.0 · release gate (draft)

This is a **work checklist**, not a claim that a Pixel 8 has passed. The v0.3.0 scope is the new public identity, original launcher artwork, new GitHub repository URL and live **manual prefix** suggestions in ET/EN. An experimental release requires the signed update/identity, packaged dictionaries, scoped editor tests, permissions and installed ET/EN smoke checks; unchecked physical-phone, locale/theme and broader legacy-suite coverage below remain disclosed limitations, not silently passed tests. Gboard parity beyond this slice is separately prioritized in [the roadmap](../plans/viipio-gboard-parity.md).

- [x] Keep Android application ID `io.github.tehisaru.estonianswipe`; ARM64 v0.3.0 versionCode is `3002`, higher than v0.2.3's `2032` (`aapt dump badging`).
- [x] Signed ARM64 APK certificate SHA-256 matches the public v0.2.3 release: `14fc12fab45b2f3b0b577393945bb7991f8e9bd8573c32f7844e15f936323853`. The private signing key stays outside Git.

All six compiled `mipmap/ic_launcher` resource configurations and vector resources occur in the signed APK; installed light/dark launcher comparison remains open.

- [x] Updated *active* launcher/settings links to the new repository, left historical source/release records intact, and documented Obtainium's source URL migration in `README.md`.

## Manual prediction and privacy

- [x] ET and EN typing displayed up to three offline prefix matches in the installed x86_64 APK; both CKDT V2 dictionaries are packaged in every built ABI APK. No automatic replacement. In a simulated clean build, Gradle copied the tracked English CKDT V2 dictionary byte-identically instead of generating the incompatible V1 DICT file.
- [x] Choosing an ET candidate replaced only the verified prefix in the installed preview editor; unit tests reject changed editor, selection, context and unreadable readback without deleting unrelated text. Third-party editors remain unverified.
- [ ] A new field, punctuation/Space, Backspace, external cursor movement, language switch, swipe candidates and emoji-panel transitions cannot leave stale manual choices.
- [ ] Password, numeric, email, URL, incognito and no-suggestion fields are excluded by the scoped policy tests; a real third-party password/editor UI matrix remains open. The signed release APK's merged permissions contain neither Internet nor microphone access.
- [x] Targeted tests (60 JVM + 10 Python), normal build graph and minified signed release build pass. Freshly built signed x86_64 v0.3.0 updated the installed v0.2.3 on the shared emulator; ET candidate commit and EN prefix were read back, then Gboard was restored in `finally`. No physical Pixel 8 quality is claimed. The broad inherited suite was stopped after legacy failures and an out-of-memory cascade, not marked green.
