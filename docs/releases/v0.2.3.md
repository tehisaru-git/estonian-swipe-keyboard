# Estonian Swipe v0.2.3 — experimental long-press and suggestion layout update

Alphabetic keys now insert their visible corner symbol on a hold instead of only displaying a hint. The popup appears while the finger is still down; lift commits one choice, or slide to an alternative. From the supplied Gboard examples, `m` offers `?` and `g` offers `ğ`, `&`, `ǵ`, with `&` initially selected. Estonian `s`/`z` still offer `š`/`ž` while exposing their `#`/`*` corner symbols. The other letter keys use their displayed corner symbol. The popup is independently drawn; no Gboard code, artwork or models are included. Tap, qualified swipe, Backspace hold, cancel, and symbol-page behavior retain separate paths. TalkBack receives long-click and individually labeled alternative actions.

The three-slot candidate strip retains its fixed height when all three proposed words are long. Each text label stays on one line, scales down within a bounded range and ellipsizes only as needed; the complete word remains the candidate's accessibility description and each slot remains selectable. This fixes the screenshot in which long words wrapped onto the number row.

**Experimental:** A debug build on the shared Android emulator inserted `?`, `&` and the slid-to `ğ` in a real editor in light and dark modes; unit tests cover selection, cancelled holds and long candidate layout.
