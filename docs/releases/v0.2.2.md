# Estonian Swipe v0.2.2 — experimental emoji and swipe diagnostics update

This update makes emoji **browsing** the default: a dense, scrollable grid with labeled Recently used and Smileys sections, horizontal category navigation, an accessible search control, and offline Estonian/English lookup as an optional mode. The panel replaces the keyboard instead of stacking above it; the editor stays visible and the overall input-method height stays fixed. The design uses original UI code and graphics, not Gboard assets.

A long swipe now retains a sliding, fading visual trail instead of freezing after its visual point limit. Typing a letter immediately after a swiped word inserts a separator where the editor allows it. Two quick Space taps replace the first inserted space with `. ` in supported text fields; unsupported editors fall back safely instead of deleting surrounding text.

**Optional Swipe diagnostics:** Open the app → **Swipe diagnostics**, read the consent dialog and start local collection. This is OFF by default. Eligible Estonian swipes across ordinary text fields store normalized trajectory, key geometry, suggested and inserted words, and *verified* candidate/manual corrections. Passwords, URL/email/number, incognito and no-learning fields are excluded. No surrounding editor text or unrelated manual typing is stored. Each event is encrypted with Android Keystore in app-private storage. The export view is bounded to 5,000 swipes and 30 days; encrypted segments are limited to 48 MiB and may retain evicted entries until rotation or explicit erase. Use **Export JSONL file** and Android's document picker to save a readable local file. There is **no automatic USB retrieval or network upload**; connecting a phone via USB alone grants no access. See [local diagnostic guide](../eval/local-swipe-diagnostics.md) before sharing any plaintext export.

**Install:** The Pixel 8 / GrapheneOS needs the ARM64 asset `EstonianSwipe-v0.2.2-arm64-v8a.apk`, package `io.github.tehisaru.estonianswipe`, versionCode `2022`, SHA-256 `0b8fc41c1417e2d1b677e392e28f7ac46a01f84ec2538b65f693e113ffb72650`. Its signing certificate matches v0.2.1. A minified x86_64 build was installed on the shared emulator and passed a synthetic Estonian tap/swipe/word-Backspace smoke test; Gboard was restored. This does not substitute for a real Pixel 8 trial.

**Experimental limits:** The Pixel 8 physical-device look, real-finger Estonian recognition quality, latency, battery impact, and broad app-editor compatibility remain unverified. A correction that cannot be verified is left unresolved in the export rather than guessed. Keep a second keyboard enabled and review important text before sending.
