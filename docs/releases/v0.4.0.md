# Viipio keyboard v0.4.0 — candidate readability and swipe-to-tap spacing

**Experimental release.** The signed APK and its settings/typing paths were checked on a shared x86_64 emulator; this is not a physical Pixel 8 accuracy or ergonomics claim.

## Changes

- Every suggested word stays complete in one line. The candidate row scrolls horizontally **only if** the words' natural widths exceed its viewport; short words that fit remain stationary. A finger drag is not a word selection. The active offer/editor checks still apply to a tap, and TalkBack receives the full word.
- The existing verified swipe→first-manual-letter separator remains ON by default. A new **Add space after a swipe when typing** switch directly in keyboard gear → Viipio settings turns it off; when off, the letter is inserted without the automatic separator. A failed ownership/readback/combined write never deletes the user's existing text.
- Explicitly **not changed**: encrypted opt-in diagnostic data, permissions or the handling of an older word edited after the cursor moved. Android cannot prove such a later word is the same swipe instance from spelling and offset alone. The owner chose to save only firmly attributable corrections, with a separate user-declared **Mark correction** interaction to be designed later. No speculative older-word correction is recorded or used for ranking.

## Verification

- **73 scoped JVM tests and 12 Python checks passed** after the active settings route was fixed. They include complete long labels, no short-row scrolling, drag without selection, 48dp back control, spacing policy and settings routing. The broad inherited CleverKeys suite is **not** claimed green.
- A signed x86_64 APK updated an installed v0.3.1 without uninstalling. In the launcher practice editor, a synthetic ET swipe followed by `k` produced `tere k` (or `tee k`) with the default-on setting. The keyboard gear opened a visible ON switch; switching it OFF produced `terek` (or `teek`). The switch was restored ON afterwards. Gboard and the original foreground launcher were restored.
- In both installed light and dark themes, manual prefix `rahvusvahel` displayed long candidate words; dragging revealed the later full word without changing the editor, and tapping that word replaced only the prefix with `rahvusvahelisel`. A short-prefix row displayed its three words without clipping. Native-layout unit tests also measured the short row as immovable and the long row as overflowing. The original system light mode was restored after the dark check.
- The signed ARM64 APK reports package ID `io.github.tehisaru.estonianswipe`, versionCode **4002**, label `Viipio keyboard` and the **same signing certificate** as v0.3.1. Its merged permissions request no Internet or microphone access. The local signed ARM64 SHA-256 is `0890a8a9ad1762a2cb3e663f858e38a590dbf86f53ad606ce2d6fc5c8ffe6b41`; the public asset is compared against this value during publication.
- **Unverified:** physical Pixel 8 finger comfort and swipe accuracy, consented diagnostics export/readback and third-party controlled editors. No new older-word diagnostic capture is part of this release.
