# Viipio keyboard v0.3.0 — experimental rebrand and typed-word suggestions

**Experimental release.** The scoped evidence and openly incomplete checks are recorded in [`v0.3.0-gates.md`](v0.3.0-gates.md); this is not a full Gboard parity or Pixel 8 quality endorsement.

## Changes

- The app, Android input-method selector and setup screen now use the user-selected name **Viipio keyboard**. Original launcher artwork has an adaptive vector, a monochrome themed-icon mask and reproducible legacy PNGs for five densities. The setup screen keeps a two-step enable/select flow and explains the active ET/EN switch and bundled dictionaries rather than linking to dormant CleverKeys configuration.
- Source repository: <https://github.com/tehisaru-git/viipio-keyboard>. GitHub redirects the previous `tehisaru-git/estonian-swipe-keyboard` URL; previous tagged releases remain available. In-app source and release links target the new address.
- The active keyboard offers up to three offline dictionary completions while letters are typed. Candidate selection verifies the current editor, collapsed caret, surrounding text and exact selected prefix before replacement. It never silently autocorrects. Password, no-suggestion, numeric, URL and email fields do not offer manual completions. ET and EN are separately selected.

## Install/update compatibility

The Android application ID remains `io.github.tehisaru.estonianswipe`; the ARM64 v0.3.0 versionCode is **3002**. Existing installations can update in place **only** if the new APK has the same signing certificate as v0.2.3. Use one signed `ViipioKeyboard-v0.3.0-arm64-v8a.apk` in the GitHub Release; no debug build or source archive is an installable replacement. Existing user data should remain, but verify an actual update before claiming it.

## Limits and evidence (pending final verification)

- Completions use bundled Estonian/English dictionaries; imported dictionary packs are not yet included in this new suggestion path. The tracked English CKDT V2 source is copied into the packaged asset on a clean build; a local simulation that removed the ignored asset regenerated it byte-identically. No automatic typo correction or personalization is claimed.
- Full Gboard parity, genuine Pixel 8 typing accuracy/ergonomics and all third-party editors remain unverified. GIF search and voice input are not priorities in this preview; keep another keyboard installed and check important text.
- Targeted Robolectric/JUnit run: **60 tests, 0 failures** across five relevant classes; ten Python brand/packaging/routing checks pass. The broad inherited `testDebugUnitTest` run reported legacy failures (including upstream CleverKeys-only release-channel checks) and eventually a worker `OutOfMemoryError` cascade; it was stopped, **not counted as passing**. Release-relevant failures must be isolated before publication. A clean-build simulation reproduced the ignored English asset byte-identically from the tracked CKDT V2 source, and both ET/EN V2 binaries occur in all built ABI APKs. The minified signed ARM64 APK reports application label `Viipio keyboard`, package ID unchanged, versionCode **3002**, and the same SHA-256 certificate fingerprint as the public v0.2.3 APK; `aapt dump permissions` lists neither Internet nor microphone access. On the shared emulator, signed x86_64 v0.3.0 installed over v0.2.3 without uninstalling, ET `ter` displayed `terve / tervise / tervis`, tapping `terve` changed the editor from `ter` to `terve`, and after switching to EN the typed `te` displayed `team / tell / term`. Gboard and the prior foreground launcher were restored. This is not a physical Pixel 8 test or a full editor/privacy matrix.
- The Viipio name was chosen by the user after preliminary checks, not a legal trademark clearance. CleverKeys/GPLv3 and language-data attribution remain in `NOTICE`.
