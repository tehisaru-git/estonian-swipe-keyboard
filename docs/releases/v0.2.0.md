# Estonian Swipe v0.2.0 — experimental Pixel 8 test build

This is the first release with the independently drawn keyboard as the **active input method**. It uses CleverKeys-derived CTC/geometric swipe decoding, not the old CleverKeys keyboard view. The Estonian offline word list is bundled; no ZIP import is needed for basic Estonian prediction. The English layout and recognition are selected separately with the ET/EN key. Offline emoji search accepts Estonian and English query taps. `s`/`z` long-press types `š`/`ž` in Estonian.

**Install:** Download `EstonianSwipe-v0.2.0-arm64-v8a.apk` on a Pixel 8 / GrapheneOS. Open the app, enable it in Android's keyboard settings, then select it. Keep your previous keyboard installed. An existing v0.1.0 installation can be updated in place with the same signing certificate and a higher version code. Obtainium users can add `https://github.com/tehisaru-git/estonian-swipe-keyboard` as the app source.

**Verified before publication:** targeted unit tests for the independent service, touch geometry, suggestions, emoji, Estonian dictionary, settings and packaging; a minified release on an Android emulator for Estonian and English taps and synthetic swipes, correction, emoji insertion and light/dark appearance; an in-place signed update (x86_64 emulator variant); ARM64 APK certificate, package, version code, bundled assets and permissions. The release requests no Internet or microphone permission. ARM64 SHA-256: `454f7a31453732e9bcf9fed99fe0edee8b3e523bc866fb1a4d8fdf461476025f`.

**Not yet verified:** real-finger Estonian top-1/top-3 accuracy, latency or ergonomics on a Pixel 8; broad app/editor/TalkBack coverage and battery impact. The inherited all-project test suite was interrupted after memory exhaustion and legacy failures; its green status is **not** claimed. Do not rely on this experimental keyboard for important text without reviewing it. Report failing words, selected language, exact editor app, and whether a correction was possible; do not send private text or passwords.
