# Viipio keyboard v0.3.1 — diagnostics entry restored

**Experimental patch release.** The signed APK and visible opt-in route were verified on a shared x86_64 emulator; no user data was recorded or exported during the check.

v0.3.0 kept the local encrypted swipe-diagnostics screen and its data, but the launcher redesign removed its only direct link. The feature was therefore not discoverable from the app. v0.3.1 restores a visible **Swipe diagnostics → Open diagnostics** card in the main Viipio keyboard app, above the typing practice field.

Opening that screen does **not** start collection. The user must press **Start local collection** and confirm the consent dialog. Diagnostics remain off by default; **Export JSONL file** opens Android's user-selected document picker, and **Stop collection** / **Erase local data** remain available. This is a local file export, never a remote upload. Existing encrypted data is not deleted by this patch. Ordinary chat words can be included while enabled, so read the consent text first.

No IME prediction, dictionary, Android application ID or signing-certificate change was made. The ARM64 APK reports versionCode **3012**, package ID `io.github.tehisaru.estonianswipe`, label `Viipio keyboard`, the same signing-certificate SHA-256 as v0.3.0, and no Internet or microphone permission. Nineteen scoped JVM tests and eleven Python checks passed. A signed x86_64 v0.3.1 APK updated an installed v0.3.0 without uninstalling; the launcher card opened `TelemetryActivity`, displaying **Collection: OFF**, Start/Stop, Export JSONL and Erase. Gboard and the previous foreground app were restored. No diagnostic recording or export was performed during this check. A physical Pixel 8 verification and consented export/readback remain separate follow-ups. The broad inherited CleverKeys suite is not claimed green.
