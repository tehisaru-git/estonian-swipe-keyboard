# Estonian Swipe v0.2.1 — experimental Pixel 8 update

This update redraws the original key surface to follow the supplied Pixel 8 Gboard **layout and behavior**, without using Gboard assets: a pale-blue full-height background and navigation area, larger keys, small secondary symbols, rounded controls, a saturated blue Enter, a wide spacebar, and a fixed-height top strip that switches between an operable toolbar and inline word candidates. The ET/EN language switch moves from beside the spacebar into the toolbar. The user's Pixel 8 comparison screenshot prompted this change; exact physical-device visual alignment remains to be checked after install.

It also adds a held Backspace repeat, a left-swipe on Backspace to delete a preceding word, and one-press deletion of a word immediately after it was swiped. A swipe trail is visible over the letter keys. The fixed-height top strip prevents candidate appearance from changing the editor's vertical space.

**Optional Swipe study:** Open the app and select **Swipe study**, then **Start**. Swipe prompted words in its own test field. The session records only prompted gestures and a bounded subset of candidate information in memory while this screen is active. It does not collect other apps' editor text, clipboard, passwords or device identity, and has no network upload. **Export JSON** opens Android's file picker; save the file and attach it in the project discussion after reviewing it. The prompt list has 20 Estonian and 8 English words; switch ET/EN at the language boundary. No unattended collection or remote access to the phone is provided.

**Install:** Download the ARM64 APK on your Pixel 8 / GrapheneOS. If v0.2.0 is already installed, this installs as an in-place update using the same developer certificate and higher version code. The ARM64 package is `io.github.tehisaru.estonianswipe`, versionCode `2012`; SHA-256 `a4e1fc629f586a5950c1f87e23350f760104781ad3d9eb91c120798b024dc53f`. Keep a second keyboard enabled, and review important text before sending it. The physical phone's top-1/top-3 Estonian swipe accuracy, latency, ergonomics, broad editor coverage, accessibility and battery impact remain unverified. Emulator gestures and timing are not substitutes for a real finger on the Pixel 8.
