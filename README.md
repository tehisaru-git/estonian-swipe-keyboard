# Viipio keyboard (experimental)

**Viipio keyboard** is an experimental, offline Android keyboard with an independently drawn Estonian/English interface and CleverKeys-derived CTC/geometric swipe recognition. Licensed under GPL-3.0; [CleverKeys](https://github.com/tribixbite/CleverKeys) is credited in [NOTICE](NOTICE) and its original README is [archived here](UPSTREAM_README.md). No Gboard code, model, artwork or word list is included. The app was previously called **Estonian Swipe**; the package ID `io.github.tehisaru.estonianswipe` and release-signing certificate remain unchanged so existing installations can update in place. The product name is a user-selected brand, not a declaration of trademark clearance.

**v0.3.0 is an experimental Pixel 8 / GrapheneOS update, not a dependable daily-keyboard claim.** It adds an original adaptive icon and up to three live offline completions for words typed by hand in the separately selected ET/EN language; tapping one replaces only the verified prefix. The independently drawn layout follows the user-supplied Gboard reference without copying its assets. Long-press choices, emoji browsing/search and optional local diagnostics remain available. Real-finger Estonian top-1/top-3 accuracy, latency, ergonomics, battery use and physical Pixel 8 visual alignment have **not** been measured. Keep another keyboard installed; check important text before sending. The [Gboard feature map and prioritized Viipio milestones](docs/plans/viipio-gboard-parity.md) distinguish the active IME from dormant CleverKeys modules and do not claim measured feature-use frequencies.

## Install or update on Pixel 8

1. Download **`ViipioKeyboard-v0.3.0-arm64-v8a.apk`** from the [v0.3.0 GitHub Release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.3.0), or add `https://github.com/tehisaru-git/viipio-keyboard` in Obtainium's **Add App** screen and install the current release. Existing Obtainium users should change their source to the new repository URL if the old redirected source stops updating; the old releases are preserved. The normal release contains one APK. Do not choose a debug APK or upstream CleverKeys APK.
2. Android may ask whether the app used for the download is allowed to install packages. Open **Viipio keyboard**, choose **Enable keyboard** and **Select keyboard**. Keep Gboard or your previous keyboard installed for a quick switch back.
3. Use **ET/EN in the toolbar** for separate Estonian and English recognition. The Estonian and English word lists are bundled; the old v0.1.0 `langpack-et.zip` import is **not required**. While typing a word, tap one of the three dictionary completions to replace only that word; nothing is automatically corrected, and suggestions are hidden in sensitive or unsuitable fields. Hold a letter for its small corner symbol (`m` → `?`; `g` → `&`) or slide across a multi-choice popup (`g` also offers `ğ` and `ǵ`). Estonian `s`/`z` retain `š`/`ž` and offer `#`/`*`. Three long suggestions stay on one row; their full spelling is available to accessibility even if visually shortened. Use `?123` for symbols and the emoji key to browse or search offline. Backspace hold repeats, a short leftward swipe deletes a word, and one Backspace tap immediately after a swipe deletes that word. **Swipe diagnostics** requires explicit consent and a local JSONL export; see [privacy and USB instructions](docs/eval/local-swipe-diagnostics.md).

The app ID is `io.github.tehisaru.estonianswipe`; v0.3.0 ARM64 has versionCode `3002` (v0.2.3: `2032`). The developer-signed release uses the same private update certificate as earlier versions; a signed v0.2.3 → v0.3.0 upgrade was checked on the x86_64 emulator without uninstalling the app. Do not mix differently signed builds. The private key is outside Git.

## Scope and known limits

- The active IME is `EstonianSwipeService`, with its own measured key surface, touch controller, suggestions and emoji panel. Legacy CleverKeys keyboard/view/settings code remains in the source during migration but is not the visible keyboard.
- Swipe, dictionaries and emoji search run locally. The release APK requests **no Internet or microphone permission**. GIF search and voice input are not part of this preview. Diagnostics is **OFF by default**; if enabled, it stores only eligible Estonian swipes and verified corrections in encrypted local files, not unrelated manual typing, and never uploads them. Password fields are excluded.
- An experimental 95,000-form Estonian lexicon is bundled and attributed to the [HeliBoard/Leipzig CC BY 4.0 source](docs/specs/estonian-offline-dictionary.md). Word-form coverage is **not** evidence of swipe accuracy. Updated language packs can still be imported through Settings.
- A bounded v0.3.0 suite (60 Robolectric/JUnit tests plus 10 Python checks) and a minified signed x86_64 emulator upgrade/ET-EN typing smoke test passed. The broad inherited CleverKeys suite reported legacy failures and was stopped after a worker out-of-memory cascade; it is **not** a passing full-suite claim. An isolated legacy release-record failure references a launcher test method already absent from the v0.2.3 HEAD, not a newly broken v0.3.0 anchor. Device-specific typing, privacy-editor coverage and performance tests remain open. See [human-swipe research](docs/eval/human-swipe-research.md), [emulator limits](docs/eval/emulator-test-reliability.md) and the [UI specification](docs/specs/estonian-swipe-ui.md).

## Source and reproducibility

The [Viipio identity guide](docs/branding/viipio.md) defines the app name, original icon, light/dark colors and update-compatibility checks. This repository is a GPLv3 **source snapshot**, based on CleverKeys commit `8335bd0`, not the upstream project's release history or F-Droid channel. The inherited `fastlane/` and `metadata/fdroid/` directories describe CleverKeys, not an Estonian Swipe listing. Third-party licenses and the offline emoji source are listed in [NOTICE](NOTICE). The upstream debug signing key and release/deployment workflows were intentionally excluded from this fork.

Build with Java 17 and Android SDK platform 34: `bash scripts/gradle-guard.sh assembleDebug`. The tracked English CKDT V2 dictionary at `scripts/dictionaries/en/en_enhanced.bin` is copied into the ignored production asset on a clean build; the bundled Estonian binary remains under `src/main/assets/dictionaries/`. A developer-signed release requires `RELEASE_KEYSTORE`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS` and `RELEASE_KEY_PASSWORD` outside Git; otherwise `assembleRelease` does not produce a publishable signed update. Do not publish an upstream or debug-key-signed release.
